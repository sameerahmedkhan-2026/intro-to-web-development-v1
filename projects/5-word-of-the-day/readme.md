# word of the day app

GET https://words.dev-apis.com/word-of-the-day
This will give you the word of the day. It changes every night at midnight

https://words.dev-apis.com/wordof-the-day/get-word-of-the-day?random=1
gives a random word of the day, not just the same daily one.

https://words.dev-apis.com/wordof-the-day/get-word-of-the-day?puzzle=1337

use insomnia or postman to test the api.

403 error - means you may not have formed the request correctly. check the docs for the api to see what it expects.
